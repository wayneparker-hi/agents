# 可变点矩阵与配置

## 目的

可变点矩阵是一个快速参考表，用于：
- 列出流程中的所有可变点
- 识别变化维度
- 记录各个选项及其条件
- 管理配置参数

---

## 矩阵模板

### 完整矩阵结构

```
流程名称：[流程名]

┌─────────────────┬──────────────┬──────────────┬────────────────┬──────────────────┐
│ 流程步骤        │ 可变点名称   │ 变化维度     │ 选项数         │ 优先级           │
├─────────────────┼──────────────┼──────────────┼────────────────┼──────────────────┤
│ [步骤名]        │ [可变点名]   │ [维度]       │ [数字]         │ 高/中/低         │
├─────────────────┼──────────────┼──────────────┼────────────────┼──────────────────┤
│ ...             │ ...          │ ...          │ ...            │ ...              │
└─────────────────┴──────────────┴──────────────┴────────────────┴──────────────────┘
```

## 实际例子：订单处理流程

### 可变点概览矩阵

```
流程名称：订单处理全流程

┌─────────────────────┬──────────────────────┬──────────────────────┬────┬────────┐
│ 流程步骤            │ 可变点名称           │ 变化维度             │ # │ 优先级 │
├─────────────────────┼──────────────────────┼──────────────────────┼────┼────────┤
│ 订单创建后          │ 风险检查策略         │ 风险等级 + 信誉等级  │ 4  │ 🔴高   │
├─────────────────────┼──────────────────────┼──────────────────────┼────┼────────┤
│ 库存预留后          │ 发货方式选择         │ 商品类型 + 地区      │ 4  │ 🔴高   │
├─────────────────────┼──────────────────────┼──────────────────────┼────┼────────┤
│ 仓库出库前          │ 发货时间策略         │ 订单时间 + 库存      │ 3  │ 🟡中   │
├─────────────────────┼──────────────────────┼──────────────────────┼────┼────────┤
│ 物流揽件后          │ 物流商选择           │ 地区 + 时效要求      │ 5  │ 🟡中   │
├─────────────────────┼──────────────────────┼──────────────────────┼────┼────────┤
│ 客户收货后          │ 售后服务流程         │ 商品类型 + 投诉内容  │ 3  │ 🟢低   │
└─────────────────────┴──────────────────────┴──────────────────────┴────┴────────┘
```

### 可变点 1：风险检查策略

```
可变点：风险检查策略
所在步骤：订单创建完成 → 支付处理之前
变化维度：订单风险等级（0-1.0）+ 用户信誉等级（1-5）

┌────┬──────────────────┬─────────────────────────────────┬──────────────────────┐
│ # │ 选项名           │ 触发条件                         │ 处理方式             │
├────┼──────────────────┼─────────────────────────────────┼──────────────────────┤
│ 1  │ 自动通过         │ 风险 < 0.3 AND                  │ 直接进入支付流程     │
│    │                  │ 信誉 >= 4                       │ (秒级完成)          │
├────┼──────────────────┼─────────────────────────────────┼──────────────────────┤
│ 2  │ 快速审核         │ 0.3 <= 风险 < 0.6 OR            │ 发送通知给审批员     │
│    │                  │ 信誉 == 3                       │ 期限：24 小时        │
├────┼──────────────────┼─────────────────────────────────┼──────────────────────┤
│ 3  │ 严格审核         │ 0.6 <= 风险 <= 1.0 OR           │ 电话 + 视频核实      │
│    │                  │ 信誉 < 3 OR                     │ 期限：48 小时        │
│    │                  │ 金额 > 50000                    │ 负责人：高级审批员  │
├────┼──────────────────┼─────────────────────────────────┼──────────────────────┤
│ 4  │ 直接拒绝         │ 黑名单 = true OR                │ 取消订单、退款       │
│    │                  │ 欺诈标志 = true OR              │ 记录原因、通知客户   │
│    │                  │ 风险 = 1.0                      │ (分钟级完成)        │
└────┴──────────────────┴─────────────────────────────────┴──────────────────────┘

配置参数：
  - autoApprovalThreshold: 0.3
  - creditLevelGood: 4
  - creditLevelBad: 3
  - approvalTimeout: 24h
  - strictReviewTimeout: 48h
  - largeOrderThreshold: 50000

计算公式（风险等级）：
  riskScore = (
    amountAnomalyScore * 0.4 +          # 金额异常
    addressRiskScore * 0.2 +             # 地址风险
    frequencyAnomalyScore * 0.2 +        # 频率异常
    blacklistScore * 0.2                 # 黑名单
  )
```

### 可变点 2：发货方式选择

```
可变点：发货方式选择
所在步骤：库存预留完成 → 仓库出库或自动发送
变化维度：商品类型（4 种）+ 客户地区（3 种）

商品类型：
  - PHYSICAL：实物商品
  - VIRTUAL：虚拟商品
  - PRESALE：预售商品
  - GROUPBUY：团购商品

客户地区：
  - DOMESTIC：国内（含港澳台）
  - INTERNATIONAL：国际
  - RESTRICTED：受限地区

┌────┬──────────────────┬──────────────────────────────┬──────────────────────────┐
│ # │ 选项名           │ 触发条件                     │ 处理方式                 │
├────┼──────────────────┼──────────────────────────────┼──────────────────────────┤
│ 1  │ 标准物流         │ type = PHYSICAL AND          │ 仓库出库 → 扫描商品     │
│    │                  │ region = DOMESTIC            │ 生成发货单 → 物流揽件   │
│    │                  │ stock >= quantity           │ 时效：1-3 天            │
├────┼──────────────────┼──────────────────────────────┼──────────────────────────┤
│ 2  │ 虚拟自动发送     │ type = VIRTUAL              │ 生成兑换码/ 下载链接    │
│    │                  │ (region 无关)               │ 发送给客户 (邮件/短信)  │
│    │                  │                              │ 时效：秒级完成          │
├────┼──────────────────┼──────────────────────────────┼──────────────────────────┤
│ 3  │ 等待拼团         │ type = GROUPBUY AND         │ 订单进入拼团队列        │
│    │                  │ groupStatus != COMPLETED    │ 等待达到最少数量        │
│    │                  │                              │ 时效：可能较长          │
├────┼──────────────────┼──────────────────────────────┼──────────────────────────┤
│ 4  │ 国际物流         │ type = PHYSICAL AND         │ 海外仓出库 / 国际快递   │
│    │                  │ region = INTERNATIONAL      │ 清关处理                │
│    │                  │ hasInternationalStock = true│ 时效：7-15 天           │
├────┼──────────────────┼──────────────────────────────┼──────────────────────────┤
│ 5  │ 合作商直发       │ type = PHYSICAL AND         │ 品牌仓库直接发货        │
│    │                  │ partnerAvailable = true AND │ 物流：由品牌方负责      │
│    │                  │ region = DOMESTIC           │ 时效：1-2 天            │
└────┴──────────────────┴──────────────────────────────┴──────────────────────────┘

配置参数：
  - partnerRegions: [华东, 华中, 华南]
  - groupBuyMinCount: 10
  - internationalCountries: [全部非中国地区]
  - standardShippingRegions: [全部国内地区]

路由规则优先级：
  1. 虚拟商品检查（VIRTUAL）→ 自动发送
  2. 黑名单地区检查 → 拒绝
  3. 合作商检查 → 直发
  4. 地区检查 → 国际物流 or 标准物流
  5. 拼团检查 → 等待拼团
```

### 可变点 3：发货时间策略

```
可变点：发货时间策略
所在步骤：库存确认完成 → 生成发货单
变化维度：订单时间（工作时间 vs 非工作时间）+ 库存充足度（0-100%）

┌────┬──────────────────┬──────────────────────────────┬──────────────────┐
│ # │ 选项名           │ 触发条件                     │ 发货时间         │
├────┼──────────────────┼──────────────────────────────┼──────────────────┤
│ 1  │ 当天发货         │ 订单时间 in [09:00-17:00]   │ 同日发货         │
│    │ (加急)           │ AND 库存充足 (>= 100%)       │ (2 小时内)       │
├────┼──────────────────┼──────────────────────────────┼──────────────────┤
│ 2  │ 次日发货         │ 订单时间 NOT in [09:00-17:00]│ 下个工作日       │
│    │ (标准)           │ OR 库存需补 (80-99%)         │ (24 小时内)      │
├────┼──────────────────┼──────────────────────────────┼──────────────────┤
│ 3  │ 约定时间发货     │ 大订单 (>= 50 件) AND       │ 客户承诺时间     │
│    │ (VIP/大单)       │ (库存充足 OR 供应商确认)    │ (最长 3 天)      │
├────┼──────────────────┼──────────────────────────────┼──────────────────┤
│ 4  │ 等待补库         │ 库存不足 (< 80%)             │ 等待补库         │
│    │ (等待)           │ AND 补库 ETA 已知           │ (最长 7 天)      │
└────┴──────────────────┴──────────────────────────────┴──────────────────┘

配置参数：
  - businessHours: [09:00-17:00]
  - businessDays: [周一-周五]
  - largeOrderThreshold: 50 件
  - maxWaitDays: 7
  - urgentSLA: 2 小时
  - standardSLA: 24 小时
```

### 可变点 4：物流商选择

```
可变点：物流商选择
所在步骤：发货单生成完成 → 物流揽件
变化维度：收货地区（直辖市 vs 省份）+ 时效要求（普通 vs 急速）

┌────┬──────────────────┬──────────────────────────────┬────────────────────┐
│ # │ 选项名           │ 触发条件                     │ 物流商              │
├────┼──────────────────┼──────────────────────────────┼────────────────────┤
│ 1  │ 顺丰快递         │ 时效 = 急速 OR              │ 顺丰 (SF123)        │
│    │ (高成本, 高质量)  │ region in [直辖市]          │ 时效：1-2 天        │
├────┼──────────────────┼──────────────────────────────┼────────────────────┤
│ 2  │ 中通快递         │ 时效 = 普通 AND             │ 中通 (ZTO)          │
│    │ (中等成本)        │ region in [一线城市所在省]  │ 时效：2-3 天        │
├────┼──────────────────┼──────────────────────────────┼────────────────────┤
│ 3  │ 圆通快递         │ 时效 = 普通 AND             │ 圆通 (YTO)          │
│    │ (低成本, 覆盖广)  │ region in [其他省份]        │ 时效：3-5 天        │
├────┼──────────────────┼──────────────────────────────┼────────────────────┤
│ 4  │ 标准快递 EMS     │ 时效 = 普通 AND             │ EMS / 中国邮政      │
│    │ (最后一公里)      │ region = 偏远地区           │ 时效：5-7 天        │
└────┴──────────────────┴──────────────────────────────┴────────────────────┘

配置参数：
  - expressLogistics: {顺丰: SF123}
  - standardLogistics: {中通: ZTO, 圆通: YTO}
  - remoteLogistics: {EMS: '中国邮政'}
  - costConfig:
    - express: 25 元/件
    - standard: 12 元/件
    - remote: 18 元/件
```

### 可变点 5：售后服务流程

```
可变点：售后服务流程
所在步骤：客户收货 → 投诉处理
变化维度：商品类型（物理 vs 虚拟）+ 投诉类型（破损 vs 不符等）

┌────┬──────────────────┬──────────────────────────────┬──────────────────────┐
│ # │ 选项名           │ 触发条件                     │ 处理方式             │
├────┼──────────────────┼──────────────────────────────┼──────────────────────┤
│ 1  │ 无条件退货退款   │ 投诉 in [破损, 丢失] AND    │ 邮费补贴 → 直接退款  │
│    │ (高风险商品)     │ product.riskLevel = HIGH    │ 时间：24 小时        │
├────┼──────────────────┼──────────────────────────────┼──────────────────────┤
│ 2  │ 有条件退货       │ 投诉 in [破损] AND          │ 需要寄回商品         │
│    │ (标准商品)       │ product.riskLevel = LOW     │ 验证后退款           │
│    │                  │ amount < 1000               │ 时间：5-7 天         │
├────┼──────────────────┼──────────────────────────────┼──────────────────────┤
│ 3  │ 虚拟商品退款     │ type = VIRTUAL AND          │ 直接原额退款         │
│    │ (秒级处理)       │ 投诉存在                    │ (自动处理)          │
├────┼──────────────────┼──────────────────────────────┼──────────────────────┤
│ 4  │ 人工审核         │ 金额 > 1000 OR              │ 人工审批             │
│    │ (高价商品)       │ 投诉复杂                    │ 时间：24-48 小时    │
└────┴──────────────────┴──────────────────────────────┴──────────────────────┘

配置参数：
  - highRiskProducts: [贵重物品, 易碎品]
  - autoRefundThreshold: 1000
  - complexClaimKeywords: [多件缺失, 严重破损等]
```

## 总结

### 优先级排序

```
高优先级（影响收入/用户体验）：
  1. 风险检查策略（4 个选项，保护公司）
  2. 发货方式选择（4 个选项，影响成本和体验）
  3. 物流商选择（4 个选项，影响成本和时效）

中优先级（优化流程）：
  1. 发货时间策略（4 个选项，影响 SLA）

低优先级（被动应对）：
  1. 售后服务流程（3 个选项，应对投诉）
```

### 配置管理

所有参数应该存储在：
- **数据库表**：`process_variability_config`
- **配置文件**：`application-variability.yaml`
- **管理后台**：提供 UI 修改配置

### 定期评审

- **每个季度**：评审当前选项是否覆盖所有真实情况
- **每个月**：分析每个选项的触发频率
- **实时监控**：检查是否有无法匹配的场景（"其他"选项触发过多）
